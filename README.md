# 💼 Job Portal - MERN Stack

A full-stack **Job Portal** built using the **MERN Stack** that connects job seekers with recruiters. The platform provides role-based authentication, allowing recruiters to post and manage job openings while candidates can search and apply for jobs seamlessly.

## 🚀 Features
### 👨‍💼 For Job Seekers
- User Registration & Login
- Secure JWT Authentication
- Browse available job listings
- Search and filter jobs
- Apply for jobs
- View applied jobs
- Update profile information
### 🏢 For Recruiters
- Recruiter Registration & Login
- Create, Edit & Delete Job Posts
- View all posted jobs
- Manage job applications
- Update recruiter profile
### 🔒 Authentication & Security
- JWT-based Authentication
- Password Encryption using bcrypt
- Protected Routes
- Role-Based Authorization

## ⚙️ Installation
### Clone the Repository
```bash
git clone https://github.com/Rajannya214/jobportal_mern.git
```
Move into the project directory
```bash
cd jobportal_mern

## Backend Setup
bash
cd backend
npm install

Create a `.env` file inside the backend folder.

Example:
env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
Start Backend
bash
npm start
or
bash
npm run dev
## Frontend Setup

```bash
cd frontend
npm install
npm start
```

The application will run on:

Frontend

```
http://localhost:3000
```

Backend

```
http://localhost:5000
```
